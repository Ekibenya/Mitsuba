> 银发，蓝眼，肌肤雪白得像人偶。
>
> 世人叫她「诅咒人偶」。沉睡十年的公爵家长女在大轮历585年的春末睁开了眼睛——然后，这个魔术与大炮并存、贵族与市民对立、战争与革命接踵而至的国家，再也没能太平过。
>
> 你就是她。没有固定选项，没有既定结局。你说的每一句话、做的每一件事，都会被国家文书馆的书记官记入档案，成为罗泽利亚历史的一部分。

**《三叶物语·死之轮舞》** 是一款类 SillyTavern 的 AI 角色扮演游戏：AI 扮演整个世界——继母、军校战友、断头台议长、傀儡国王、宿敌帝国的皇帝、贩夫走卒——而你以三叶・克劳伯之身（或原作任何一位人物、或你自创的角色），从苏醒之年走向革命与共和国。

本作基于轻小说《みつばものがたり　呪いの少女と死の輪舞》（1-3卷）的中文同人角色卡制作，与《周纪·千年天下》同款引擎。

## ✦ 文字侧 · AI 世界叙事

- **🎭 无固定选项、无预设结局** — 言语 / 举动 / 自由 / **控制游戏**四种行动方式，外加**聊天模式**快聊
- **⚡ 流式输出** — 字随生成边打边现（OpenAI 兼容 / Claude / Gemini 三家全支持），任何流式故障自动回退整段生成
- **📖 原作级世界书 · 249条** — 人物68／剧情时间线41／地理32／社会30／军事34／政治35／核心规则9，基于原作全文逐字精读提取，人物条目带【卷N】时点标记防未卜先知；玩家可自写条目、上传 SillyTavern 世界书
- **🀄 文书馆档案状态栏** — 每回合更新：我之起居（衣装 / 持物 / 身体 / 观瞻 / 人望 / 书记官记录）、在场之人好感与心声、时局天下大势；**人物关系图谱**与**编年史**常驻
- **🧠 长程记忆 · 编年长卷** — 每一轮自动摘为一条编年纪要，**永久保存并每轮全文送呈 AI**：即使模型上下文很短、正文历史被截断，它也始终记得这一局发生过什么；支持手记入卷、逐条编辑、随存档封存
- **🗺️ 罗泽利亚舆图** — 从首都贝尔到贝里埃要塞、从布鲁洛兹州到宿敌普尔梅尼亚，拖动「叶」子即为亲赴其地
- **🎲 命运之骰 / 懒人四策 / 绘此幕 / 诵此幕** — 掷骰定成败、AI 拟四条下一步、一键为本幕配图与朗读
- **💾 存档卷宗** — 本地存档最多十二份，随时续前缘
