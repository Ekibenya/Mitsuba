## ✦ 招牌二：日文沙盒

<div align="center">

<img src="docs/shots/jpsandbox.jpg" width="90%" alt="日文沙盒" />

</div>

让 AI 的**思考与创作全程在纯日文环境中进行**，再以经典日译中腔调译出中文正文——文风严丝合缝对齐原作《みつばものがたり》：

**①** 玩家输入和訳 → **②** 日文构思 → **③** 日文正文草稿（游戏中实时直播于顶部灵动岛「和文」页）→ **④** 译笔腔调译出中文

- **单 API / 双 API 双模式**：单 API 主模型独自完成四幕，零配置；双 API 由独立「译官」接口先把输入译成日文，日文环境更纯粹，也能把翻译分给便宜模型。
- **分幕开关**：输入和訳 / 日文构思 / 日文草稿 / 译笔腔调，四幕可逐一开关。
- 顶部灵动岛在 AI 输出时自动切到「和文」页，实时直播思考与日文草稿全文。

## 其余特色

<div align="center">

<img src="docs/shots/settings.jpg" width="90%" alt="设置" />

*字号 / 透明度 / 字体 / 版式 / 生图 / 语音 / 角色卡 / 世界书 / 正则 / 助手脚本 / 多接口，逐项可调*

- **液态玻璃界面**：向苹果设计美学看齐的悬浮玻璃与渐变消隐，三色旗布料随风翻卷的开场，暗/浅两风、低配模式一键切换。
- **文书馆 · 观剧档案**：无聊与诅咒双曲线随剧情呼吸、三头制议席、双极声望条、在场之人心向、书记官如实记录——一屏读尽当下局势。
- **忠于原作的叙事引擎**：剧情贴合原作时间线，人物性格、说话方式、称呼、译名严格对齐内嵌世界书；只知当前时点已发生的事。
- **酒馆生态兼容**：直接导入 SillyTavern 角色卡（PNG / JSON）、世界书高级字段、正则脚本、助手脚本沙箱、思维链折叠、提示词透视。
- **快意操作**：流式输出、聊天模式、懒人选项、命运骰、语音输入与朗读、每幕可修可删、重演翻稿、成书导出、开局码分享。
- **绘此幕**：接你自己的绘图接口为每幕生成插画（NovelAI / ComfyUI / OpenAI 兼容 / SD 等）。

## 怎么玩

游戏本身**不自带 AI**，你接入自己的 AI 接口来驱动世界：

1. 打开在线地址（或用浏览器打开）。
2. 点「接入 AI」，填入你自己的 AI 接口地址与密钥。
3. 点「开幕」，选一个开局，开始。

存档、记忆、密钥等一切数据仅存于你的浏览器，不上传、无服务器、无数据库。
